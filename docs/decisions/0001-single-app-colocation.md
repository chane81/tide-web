# 0001. 단일 Next.js 앱 + 콜로케이션 구조

- 상태: 채택
- 날짜: 2026-11-14

## 맥락

tide-web은 배포된 tide 패키지(`@tide-design/*`)로 대시보드를 만들어 보는 확인용 앱이다. 앱은 하나이고, 다른 앱과 나눠 쓸 코드가 없다.

## 결정

- 모노레포(turbo, workspace 패키지)를 두지 않고 **Next.js 앱 하나**를 저장소 루트에 둔다.
- 파일 배치는 콜로케이션 규칙(`.claude/rules/app-structure.md`)을 따른다. 쓰는 곳 가까이 두고, 쓰는 곳이 늘면 공통 부모로 승격한다.
- tide는 workspace 링크가 아니라 **npm에 배포된 버전**을 설치한다. 실제 사용자와 같은 조건에서 확인하기 위해서다.

## 결과

- 패키지 층(shared/domains/widgets), 의존 방향 lint, 패키지 빌드 설정이 필요 없다.
- 앱이 둘 이상이 되면 그때 모노레포로 다시 검토한다.
