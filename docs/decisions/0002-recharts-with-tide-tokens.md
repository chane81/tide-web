# 0002. 차트는 Recharts, 색은 tide 토큰

- 상태: 채택
- 날짜: 2026-11-14

## 맥락

tide(`@tide-design/components` 0.11.4)에는 차트 컴포넌트가 없다. 대시보드에는 라인·막대 차트가 필요하다.

## 결정

- 차트는 **Recharts**(작성 시점 최신 3.10.1, peer: React 16.8~19)로 그린다.
- 색·글꼴·격자선은 hex를 쓰지 않고 **tide CSS 변수**를 넘긴다. 다크 테마로 바뀌면 차트도 따라간다.
- Recharts를 감싸는 파일만 `'use client'`를 적는다. 페이지와 카드는 서버 컴포넌트로 둔다.
- 차트가 없는 것은 tide의 부족한 점으로 `docs/tide-gaps.md`에 기록한다.

## 검토한 대안

- 직접 SVG: 의존성이 없지만 툴팁·축·반응형을 직접 만들어야 한다.
- 차트 없이 숫자·Progress만: 대시보드로서 확인할 거리가 줄어든다.
