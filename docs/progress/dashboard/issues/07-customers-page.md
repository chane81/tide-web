# 07: 고객 화면 (`/customers`)

Status: ready-for-agent
Blocked by: 04
Spec: [../spec.md](../spec.md) (User Stories 45–55)

## What to build

고객 목록 화면을 목업 데이터로 완성한다. 검색·상태 필터·정렬·페이지·다중 선택이 되는 테이블과 일괄 동작, 고객 상세 다이얼로그. 테이블 상태(검색어, 필터, 정렬, 페이지, 선택)는 훅 하나가 관리하고, 목록 가공은 순수 함수가 맡는다. 06에 페이지 나누기 함수가 먼저 생겼으면 규칙대로 승격해 같이 쓴다.

## Acceptance criteria

- [ ] 테이블: 이름과 Avatar, 이메일, 상태 Badge(활성·휴면·이탈), 가입일, 결제 금액.
- [ ] 이름·이메일 검색, 상태 Select 필터, 열 머리글 정렬(오름·내림)이 된다.
- [ ] 검색·필터를 바꾸면 첫 페이지로 돌아간다.
- [ ] 행 Checkbox 선택과 전체 선택(현재 결과 전체 대상), 고른 수 표시, 일괄 동작(내보내기, 삭제).
- [ ] 일괄 삭제는 tide AlertDialog 확인을 거치고, 확인하면 화면 상태에서 지워진다.
- [ ] 결과가 없으면 빈 상태 안내를 보인다.
- [ ] 행을 누르면 고객 상세 tide Dialog가 열린다. 체크박스 클릭은 상세를 열지 않는다.
- [ ] 위 동작은 RTL 테스트로, 검색·필터·정렬·페이지 함수는 단위 테스트로 확인한다.
- [ ] tide Table에 없어 직접 만든 것(정렬 머리글, 선택 열 등)은 `docs/tide-gaps.md`에 기록한다.
- [ ] 검사 명령 통과.
