# tide 부족한 점

tide 패키지로 대시보드를 만들면서 부족했던 점을 모은다. tide 저장소에 이슈로 옮길 후보다.

항목마다: 무엇이 없었나 / 어떻게 우회했나(파일 경로) / tide에 바라는 것.
